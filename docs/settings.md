# 翻译与 PDF 设置

打开 Zotero「设置 → 本地 PDF 翻译」，或点击文献列表顶部翻译图标 →「配置」。顶部可切换常规、翻译服务、翻译质量、PDF 排版和高级五类设置；切换分类保留未保存的输入。底部点击「保存配置」，在下一项任务开始时生效。

任务窗口支持复选框多选、Shift 连续选择、Ctrl / Cmd 加选与 Ctrl / Cmd + A 全选。底部可批量重试、取消或移除记录；「清空队列」会取消正在翻译的任务并清除记录，已有 PDF 和子附件会保留。

默认跳过有任意译文附件的整条文献，包括没有插件标签或已改名的 BabelDOC 译文。批量确认显示过滤后的 PDF 数量与文献数量；无法读取的 PDF 会单独提示。需要重新翻译时，关闭「跳过已有译文的文献」。

## 语言、API 与速度

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 源语言 / 目标语言 | `en` / `zh` | 可填写语言代码，也可从建议中选择；例如 `zh-TW`、`ja`、`ko`。实际支持情况取决于模型和引擎字体。 |
| Base URL / 模型 / 密钥 | 填写自己的服务 | 支持 OpenAI Chat Completions 兼容接口。密钥保存在 Zotero 登录管理器，保存或重开后以掩码显示。 |
| QPS | 4 | 限制每秒翻译请求数；根据 API 的速率限制设置。 |
| 并行线程数 | 0 | 0 表示跟随 QPS。较慢的 API 可适当增加并行线程，同时仍受 QPS 限制。 |
| API 超时 | 180 秒 | 单次 API 请求的超时上限 |
| 思考模式 | API 默认值 | 不发送额外参数；可切换开启或关闭。需模型支持。 |
| 思考参数协议 | 自动 | 官方 DeepSeek → `thinking`；官方 DashScope Qwen → `enable_thinking`；官方 OpenAI → `reasoning_effort`。第三方网关需自行选择协议，未知接口不会猜测。 |
| 思考强度 | 中 | 对 `reasoning_effort` 协议的开启模式生效，可选低、中、高。关闭发送 `none`，部分模型不支持关闭，遇到拒绝可改回 API 默认值。 |

## 质量、术语和缓存

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 最短待译文本长度 | 5 | 更短的文本块不发送翻译。较低值会增加对短标签的处理。 |
| 自动提取术语 | 开启 | 使用支持 LLM 的服务时提取文档术语，提高一致性；会增加 API 用量。 |
| 自定义系统提示词 | 空 | 替换 LLM 翻译提示中的角色描述，设置写作或术语要求；引擎仍附加格式指令。请勿要求删除公式、占位符与标记。 |
| 译文字体 | 自动 | 可选自动、衬线、无衬线、手写 / 斜体。字体由引擎提供。 |
| 忽略翻译缓存 | 关闭 | 强制重新请求 API。它与「跳过已有译文的文献」是两个独立选项；若需重新生成已有附件，两项都要相应调整。 |

提示词、字体与 PDF 排版设置会参与本地结果缓存的判断。相同配置重试可复用已生成的 PDF；设置改变时会重新生成。

## PDF 排版与扫描件兼容

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 双语布局 | 左右对照 | 可改为原文与译文交替页，适合较窄的阅读窗口。 |
| 译文在前 | 关闭 | 调整 dual 中原文与译文的顺序。 |
| 水印 | 保留 | 可选择不添加引擎水印；仍只生成一份 mono 和一份 dual。 |
| 扫描件兼容 | 关闭 | 可自动启用兼容模式，或强制采用黑字白底的 OCR workaround。不是独立 OCR 识别服务。自动模式会强制启用扫描检测。 |
| 增强 PDF 兼容性 | 关闭 | 启用引擎的兼容处理，同时关闭富文本翻译并跳过 PDF 清理。 |
| 保留富文本 | 开启 | 保留段落内样式；增强兼容性开启时以兼容模式为准。 |
| 短行分段 | 关闭 | 原 PDF 段落识别不理想时，可尝试将短行拆开。 |
| 短行阈值 | 0.8 | 短行分段的比例参数，范围为 0.1–1。 |
| 长文档分块页数 | 0 | 0 表示不分块。设为至少 50 的整数时按页数分块处理，完成后由引擎合并完整输出。 |

思考参数依据：[DeepSeek](https://api-docs.deepseek.com/guides/thinking_mode/)、[Qwen](https://www.alibabacloud.com/help/en/model-studio/deep-thinking)、[OpenAI](https://developers.openai.com/api/docs/guides/reasoning)。这控制的是请求参数，插件不展示模型的内部思考文本。当前引擎使用非流式请求；部分 Qwen 开源思考模型仅支持流式，请使用支持非流式的模型或关闭其思考模式。

从旧版本升级时，如果曾沿用 PDFMathTranslate 的全局服务，请在插件的翻译服务页重新保存接口、模型与密钥。插件不再读取全局服务文件，也不提供 CSV 术语表选项；已经保存在 Zotero 登录管理器中的密钥会保留。

## 引擎准备与排错

引擎在首次检查或翻译时自动准备。设置页底部统一显示准备状态。可关闭页面，后台继续准备；重新打开后恢复显示。下载总量已知时显示该阶段的百分比，其余阶段显示等待动画。高级页的「检查 / 准备引擎」可重试或修复缺失依赖；已下载内容会复用。此检查无需 API 密钥。安装失败不会把任务标记为完成，修复网络后可以重试任务。

文件位于 Zotero **配置目录**（不是文献数据目录）的 `local-pdf-translate/` 下：`runtime/` 放 Python 与依赖，`assets/` 放模型和字体，`jobs/` 放任务输出。运行环境不写入系统 PATH。旧版本手填的 Python 路径不再用于执行。

首次下载需要访问 GitHub、PyPI 和 BabelDOC 资源站点。遇到连接失败请先确认这些站点可访问；插件不会关闭 TLS 验证或自动修改代理。已安装环境随后直接复用；API 翻译仍需联网。版本升级若更换依赖锁，会创建独立的新环境，避免半次更新影响原环境。

## 高级设置

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 公式字体正则 / 公式字符正则 | 空 | 补充哪些字体或字符应视为公式。使用 Python 正则语法；不正确的正则会报错。 |
| 图表保护阈值 | 0.9 | 对图表内部线条的保护参数。没有具体排版问题时建议保留默认值。 |
| 跳过扫描页检测 | 关闭 | 跳过引擎的扫描页检查；可能降低输出质量。 |

## 原项目中暂未放入插件的能力

原项目还提供页码选择、单独关闭 mono / dual、独立 Web 界面、HTTP API、离线资源导入导出、调试输出及更多底层 PDF 参数。插件当前始终生成**完整的两种子附件**，因此没有开放页码裁剪和单一输出，也不在 Zotero 内重复提供独立 Web 服务或调试入口。

`translate_table_text` 虽然仍出现在 pdf2zh-next 2.9.0 配置中，但本机 BabelDOC 0.6.2 已提示旧的 RapidOCR 表格检测参数被忽略，因此插件没有提供一个看似可用、实际无效的旧表格开关。

参数依据：[PDFMathTranslate 高级配置](https://github.com/PDFMathTranslate-next/PDFMathTranslate-next/blob/main/docs/en/advanced/advanced.md)。本文记录的是插件已接入并验证的选项，具体 PDF 的效果仍取决于引擎与模型。
